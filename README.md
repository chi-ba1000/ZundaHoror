サークルメンバー4人で制作したホラーゲームです．
チーム制作はほぼ全員が初めての中，講義の間の時間をとりながら約半年間取り組みました．

役割
プログラム，ギミック：千葉，滝川
ストーリー，オブジェクト，音声：武田
UI：清水

複数人による開発経験がなかったため，githubでの進捗の共有，同時開発，統合時のコンフリクトなど一人での開発では起きない課題が多く苦労しました．
一人ひとり知識量と技術量の差を埋めつつ作業を共有することが難しかったです．
